# University Management System

A backend API for managing university academic and administrative activities.

## Features

User registration and login
Role-based authentication and authorization
Student management
Instructor management
Department management
Program management
Course management
Semester management
Fee management
Payment integration
Profile management
Profile image upload
Admin management
Input validation with Zod
Secure password hashing
JWT authentication
Centralized error handling
Pagination, filtering and searching
Soft delete
Audit logging

## User Roles

Student
Instructor
Admin

## Technology Stack

Node.js
TypeScript
Express.js
PostgreSQL
